# Software and System Access Request

**Category:** Access Management  
**Last updated:** January 2024  
**Owner:** IT Helpdesk

## Standard Access (Provisioned Automatically)

The following tools are provisioned for all employees on day one and require no request:

- Company email (Google Workspace)
- Slack
- HR portal
- Video conferencing (Zoom)
- Document storage (Google Drive)
- Password manager (1Password)
- VPN client

## Requesting Additional Software or Access

### Step 1 — Check the Software Catalogue

Before submitting a request, check the IT Software Catalogue at **intranet.company.com/it/software** to confirm the tool is already licensed. If it is listed, submit a ticket at helpdesk.company.com with:
- Tool name
- Your business justification
- Manager approval (cc your manager or note verbal approval)

Access to catalogued tools is granted within one business day.

### Step 2 — Requesting a New Tool Not in the Catalogue

If the tool is not in the catalogue, IT and Finance must evaluate it before purchase. Submit a **New Software Request** ticket with:
- Tool name and vendor website
- Business use case and which team will use it
- Estimated number of users and cost
- Whether it will process any company, employee, or customer data (data processing tools require a security review)

The evaluation process takes 5–10 business days. Security review (if required) may extend this to 20 business days.

### Step 3 — Elevated Permissions

Requests for admin, root, or elevated access to existing systems require:
- Documented justification
- Manager approval
- IT Security sign-off for any system storing Confidential data

Elevated access is reviewed quarterly and revoked automatically if not renewed.

## Access Reviews

IT conducts access reviews every six months. Managers receive a report of their team's system access and are required to confirm or revoke access within five business days. Access not confirmed will be revoked.

## Offboarding / Role Change

When an employee leaves or changes role, their manager must submit an **Access Change** ticket on the employee's last day or the date of role change. IT revokes access within two hours of receiving the request during business hours.

Do not share your login credentials with a colleague as a workaround for access issues — submit a ticket instead.
